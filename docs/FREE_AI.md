# Безкоштовний варіант парсера

Хмарна демонстрація вже доступна без localhost:
https://peach-agenda-free.peach-free-cloud-demo.workers.dev/
Див. [CLOUDFLARE_DEMO.md](CLOUDFLARE_DEMO.md). Нижче описано попередній
локальний адаптер; він залишається варіантом розробки.

Замість платного Claude використовується хмарний безкоштовний `cohere/north-mini-code:free` через OpenRouter.
Модель не завантажується на ноутбук. Завантажений раніше Ollama видалено.
Ваги моделей, локальний inference-сервер Ollama та його кеш не потрібні.

OpenRouter документує нульову ціну цього router; безкоштовні варіанти не
потребують купівлі кредитів. Без поповнення діє обмежена квота (на момент
перевірки — 50 запитів на день). Наявність вільного провайдера не гарантована.
Джерела: [free router](https://openrouter.ai/openrouter/free),
[free models](https://openrouter.ai/collections/free-models).

## Один раз: ключ

1. Відкрити https://openrouter.ai/settings/keys і ввійти або зареєструватися.
2. Create key → назва `Peach lab` → скопіювати ключ.
3. Додати в `.env` у корені проєкту `OPENROUTER_API_KEY=скопійований_ключ`.
4. Не додавати картку й не купувати credits. Не надсилати ключ у чат або Git.

Ключ використовується лише сервером і не має префікса NEXT_PUBLIC_.
За замовчуванням використовується `cohere/north-mini-code:free`. Конфігурація
дозволяє лише цю модель або `openrouter/free`; платний model ID не приймається.
Паралельні tool calls і reasoning вимкнені. Якщо квота вичерпалася, запит повертає 429, а користувач
може ввести agenda вручну. API key не додається до повідомлень помилок.

## Запуск

З кореня проєкту:

```bash
make free-ai-hello
make free-ai-parse TEXT="Pricing sync Monday 10:00. Review Pro prices — Olena, 15 minutes."
make free-ai-evaluate
```

Остання команда робить справжні API-запити для п'яти фіксованих входів і
записує `docs/ai-evidence/free-api-results.json`. Це API-перевірка, а не
прогін через deployed screen. Дозволена одна спроба виправлення на вхід,
отже весь набір може використати до 10 запитів. За 429/503 прогін зупиняється.

Для форми запустити у двох терміналах:

```bash
make free-ai-server
```

```bash
make free-ai-frontend
```

Відкрити http://localhost:3000, увійти, перейти Meetings → Agenda. Невеликий
Python-сервер на порту 8001 пересилає текст безкоштовній хмарній моделі;
на ноутбуці не виконується модель. Сервер перевіряє Cognito-токен. Збереження
використовує існуючий BACKEND_URL із `.env` та звичайний API зустрічей.
Локальний Next.js проксі пересилає `/api/v1/*` до BACKEND_URL, а
`/agenda-parser` до локального адаптера. Браузер звертається до свого origin,
тому обмеження CORS робочого AWS API не блокують локальну форму. Проксі
вмикається лише в development через `make free-ai-frontend`.
Потрібна дозволена в Cognito локальна callback URL для входу.

Ці команди не змінюють `.env` і не вмикають Bedrock в AWS. `PARSER_ENABLED=true`
та `PARSER_PROVIDER=openrouter_free` встановлюються лише для запущеного процесу.
Звичайні `make parse` / AWS-deploy зберігають попередню конфігурацію.
Нові AWS-ресурси не створюються. Нульова ціна inference не скасовує можливі
витрати вже наявного AWS-хостингу; це не обіцянка безкоштовного AWS-акаунта.

## Відмінності від умови лаби та стан

Збережено: schema/tool contract, валідацію, один repair, захист авторизованого
endpoint, ручне підтвердження, suggested-поля, вихідну ai_suggestion, облік
токенів, затримки й фактично вибраної моделі. Вартість inference — $0.
При виборі `openrouter/free` моделі можуть відрізнятися; фінальний набір
виконано на одній моделі Cohere, її ID записаний у кожній відповіді.

Це відхилення від вимоги Claude через Amazon Bedrock, яке слід погодити з
викладачем. Локальні логи не є CloudWatch evidence. Локальна форма не є
deployed-screen демонстрацією. Платний Bedrock залишається вимкненим.
Ключ доданий у виключений із Git `.env`. П’ять живих API-тестів виконано,
таблиця й аналіз: [FREE_EVALUATION.md](ai-evidence/FREE_EVALUATION.md).
Чотири agenda повернули 200, не-agenda — очікуваний 422; є змістові помилки.
Відео не записано: підключений браузер відсутній. Unit-тести адаптера
використовують mocks і не видаються за результати моделі.
